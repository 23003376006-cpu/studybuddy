# StudyBuddy - AI-Powered Learning Platform

StudyBuddy is an intelligent web application that helps students learn more effectively using AI, flashcards, quizzes, and lecture notes.

## Features

### 1. Authentication
- User login/sign-up system
- Secure password management
- User profile management

### 2. Study Materials
- **Flashcards**: Create and review flashcards for any topic
- **Quiz**: AI-generated random quizzes with multiple attempts
- **Lecture Notes**: Upload files or generate notes from topics

### 3. Content Management
- Upload files (PDFs, documents)
- Provide topic names for AI content generation
- Download lecture notes

### 4. Smart Features
- YouTube video suggestions based on topics
- Topic history tracking
- Quiz history with detailed answers
- Review previous materials anytime

### 5. Quiz System
- Random question generation each attempt
- Multiple choice questions with instant feedback
- Quiz history with MCQ answers review
- Retake quizzes unlimited times

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios (API calls)
- React Router (Navigation)

### Backend
- Node.js + Express.js
- MongoDB (Database)
- JWT (Authentication)

### AI Integration
- OpenAI API (Content generation)
- YouTube API (Video suggestions)

## Getting Started

1. Clone the repository
2. Follow SETUP.md for detailed installation instructions
3. Configure environment variables
4. Start the backend and frontend servers
5. Access the application at http://localhost:3000
